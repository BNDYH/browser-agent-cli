# DT 页面预览

可选的 macOS 菜单栏小窗口，仅显示当前操作页面的缩略图，沿用 agent-runtime 的统一 14px 内容圆角、铺满裁切和系统阴影，不画描边；窗口高度随缩略图比例调整；鼠标移入时显示右上角“打开当前页面”图标，点击激活对应浏览器标签页。整块预览可拖动，按钮区域单独排除；拖动通过指针捕获更新窗口坐标，后续命令保留本次运行中拖动后的位置，松开后将窗口约束在屏幕工作区内。悬停由原生鼠标位置判断，窗口隐藏时停止检测。抓包、任务管理与清理操作全部使用 CLI。

## 启动

在完整项目目录中执行：

```bash
npm install
npm --prefix companion ci
npm --prefix companion start
```

首次运行 Electron 可能需要下载二进制。依赖安装后，macOS 上执行 `dt` 浏览器操作命令会自动启动面板，无需单独执行 start；每次页面操作会自动显示窗口，同一状态目录只运行一个面板。设置 `DT_COMPANION=0` 可禁止 CLI 自动启动。点击菜单栏的 dt 打开/收起预览，右键可退出；退出小窗口不关闭浏览器或 daemon，下次 CLI 操作会重新启动面板。两者默认使用 `~/.dt`，隔离实例时为 CLI 和 companion 设置相同的 `DT_STATE_DIR`。

## 预览行为

没有连接到有效目标页面时不展示占位小窗；页面关闭、目标释放或连接断开后自动收起。有效目标重新出现时才按自动弹窗设置展示，手动点击菜单栏也不会打开空白占位窗。

同一 session 最多监听一页缩略图，跨 task 选择正在执行或最近操作的页面；切换后停止旧页的截图并移除旧卡片，保留浏览器 tab。多个 session 仍可同时展示各自一张卡片。

预览窗口不获取键盘焦点，自动弹出、截图更新和卡片置顶不打断其他应用的输入；鼠标拖动和打开页面按钮仍可用。只有显式点击打开页面按钮才激活对应浏览器标签页。

agent 完成整个任务后执行同一 session/task 的 `dt finish --json`，移除对应卡片；其他 scope 卡片保留，最后一张移除后面板隐藏。该命令不关闭浏览器标签页，后续 `dt open <url>` 可跨 session 复用空闲的完整 URL 匹配页，避免重复创建标签页与预览。

默认主动弹窗。菜单栏右键取消“自动弹出预览”，或执行 `dt companion off`，会隐藏窗口并在本次连接期间禁止主动弹出，仍可点击菜单栏手动打开。`dt companion on` 恢复自动弹窗，`dt companion` 查看状态。`connect` / `launch` 支持 `--no-companion`；下次成功连接默认重新开启。该选项在同一 daemon 的所有会话间共享，不写入永久配置。

- 同时显示各 scope 当前操作页面，同一标签页去重。多个页面的小窗按 32px 斜向叠放（页面较多时压缩间距）；点击任意露出部分，将该卡片排到最前面的叠放位置，其余卡片依次让位，后续截图更新保留手动顺序。拖动任一卡片移动整组，右上角按钮只打开该卡片对应的浏览器标签页。操作完成后保留卡片，直到 scope 切换页面、销毁或浏览器断开。
- 仅在打开窗口、切换目标或命令结束后更新一张最大 640 像素宽的 JPEG；连续命令合并限频。执行中保留上一帧；空闲、心跳和普通元数据事件不再触发重复截图，隐藏窗口停止截图。
- 每条页面命令结束（包括失败）自动撤掉控制标识并释放页面锁；保留连接、目标页和缓存，下次命令直接复用。`status` 的 `controlling` 表示当前 scope 是否仍在执行命令；默认 30 分钟空闲后 daemon 才退出。
- 截图经内部 `_preview` RPC 返回，不写入状态文件、审计或广播事件。预览不创建 scope/tab，不激活页面，不刷新 daemon 空闲时间；daemon 空闲退出后显示暂无预览，等待 CLI 再次启动它。
- 浏览器按当前视口原尺寸截图，在小窗进程中缩小；不通过截图 clip.scale 缩放浏览器视口，避免预览引起页面闪动。
- 页面切换、导航、关闭或断线后清除不再适用的图片；断线无需等待尚未返回的截图，过期截图响应不会恢复已移除的卡片。每张卡片底部显示更新/操作状态，执行中显示最近预览而非实时视频。预览仅是观察窗口，不能点击其中的网页内容。

## 验证与交付

```bash
npm --prefix companion test
DT_COMPANION_INTEGRATION=1 npm run test:integration
```

UI 测试使用临时 socket、独立 Electron profile 和合成页面，验证缩略图、页面选择、空闲/隐藏停止截图、按钮点击与重连。核心集成测试验证 `_preview` 返回 JPEG、不改活动时间、服从页面锁。

当前交付为完整源码目录加锁定依赖，使用上述命令启动；不能只复制 companion 目录，因为主进程复用项目中的 socket/config 模块。尚未生成签名/公证的 `.app`、DMG 或自动更新，正式安装包需将共享模块一并打包并使用发布者的签名身份。其他桌面平台未验收。

持续没有预览时，检查两边状态目录是否一致、CLI 是否已连接浏览器及选中页面。连续执行命令期间，预览可能暂时保留上一帧；这不会自动重试任何浏览器动作。
